classify.py
from anyintent import AnyIntent

clf = AnyIntent.from_pretrained(
    "lukashm/r2intent-v1",
    revision="main",
)
clf.set_labels([
    "Karte verloren", "Konto schließen",
])

text = "Ich finde meine Karte nicht mehr."
p = clf.classify(text)
print(p.label)

API-Referenz

Geben Sie jedem Intent einen Namen. Bei Bedarf können Sie eine kurze Beschreibung ergänzen. Die Liste lässt sich zur Laufzeit ändern.

Dokumentation der Python-API
classify
Gibt den passendsten Intent zurück. Das Feld margin zeigt den Abstand zwischen den Bewertungen der beiden besten Kandidaten. Bei geringem Abstand können Sie die Nachricht zur Prüfung weiterleiten.
scores
Gibt für jeden Intent einen Wert zwischen 0 und 1 zurück. Intents, die beim zweiten Bewertungsschritt übersprungen werden, erhalten den Wert 0.
check
Prüft, ob eine Nachricht zu einem bestimmten Intent passt. Die Methode liefert eine Ja-Nein-Antwort und die geschätzte Wahrscheinlichkeit für eine Übereinstimmung. In R2Intent v1 hat sie Beta-Status.
Wie R2Intent v1 Intents bewertet

Beide Durchläufe nutzen dasselbe neuronale Netz (XLM-RoBERTa large). Zunächst wählt es anhand der Kosinusähnlichkeit zur Nachricht bis zu fünf Intents aus. Anschließend bewertet es jeden dieser Kandidaten zusammen mit der Nachricht.

Der endgültige Score ergibt sich aus cross_encoder_score + 60 × cosine. Das Modell wählt den Intent mit dem höchsten Score.

Im veröffentlichten Benchmark benötigte R2Intent v1 auf einer T4-GPU bei Kaggle im Median 25,86 ms pro Nachricht (FP16, k = 5, torch.compile, CUDA Graphs und vorberechnete Intent-Vektoren).

Schnellstart

Wählen Sie, wie Sie AnyIntent einbinden möchten. Beim ersten Aufruf lädt AnyIntent das Modell herunter und speichert es im lokalen Cache.

Zugriff auf das Modell beantragen

Installieren Sie Git und Python 3.9 oder neuer. Akzeptieren Sie auf Hugging Face die Nutzungsbedingungen des Modells. Verwenden Sie für die anschließende Anmeldung ein Token mit Leserechten.

pip install "git+https://github.com/lukamaga/anyintent@v0.1.0"
hf auth login
Zum Python-BeispielInstallationsanleitung

Akzeptieren Sie auf Hugging Face die Nutzungsbedingungen des Modells und installieren Sie die Serverabhängigkeiten. Verwenden Sie zur Anmeldung ein Token mit Leserechten und starten Sie dann den Dienst.

pip install "anyintent[server] @ git+https://github.com/lukamaga/anyintent@v0.1.0"
hf auth login
anyintent-serve --model lukashm/r2intent-v1

Der Server nimmt unter 127.0.0.1:8000 Anfragen entgegen. Zur Klassifikation verwenden Sie POST /classify.

Dokumentation zum HTTP-Server

MCP setzt Python 3.10 oder neuer voraus. Akzeptieren Sie auf Hugging Face die Nutzungsbedingungen des Modells und installieren Sie die MCP-Abhängigkeiten. Verwenden Sie für die Anmeldung ein Token mit Leserechten.

pip install "anyintent[mcp] @ git+https://github.com/lukamaga/anyintent@v0.1.0"
hf auth login
anyintent-mcp --model lukashm/r2intent-v1

Standardmäßig kommunizieren Client und Server über stdio. Um eine Nachricht zu klassifizieren, ruft der Client classify_intent auf.
